SECURITY & API GUARD

Enterprise-Grade Security Architecture

Engineered with zero trust principles, strict API guards, and defensive hardening at every layer.

🛡️

Method-Level API Authorization

Every mutation endpoint is guarded with Spring Security @PreAuthorize annotations. Unauthorized elevation attempts are blocked with 403 Forbidden.

🔑

Stateless JWT & BCrypt Encryption

Tokens are signed with HMAC-SHA256 and verified on every request. Passwords use BCrypt with 10 salt rounds for brute-force resistance.

🛑

IDOR & Ownership Verification

Employees are strictly restricted to their own submitted asset requests and assigned devices. Direct object references are checked against current session claims.

🌐

Hardened Edge Reverse Proxy

Nginx applies X-Frame-Options (Clickjacking defense), X-Content-Type-Options nosniff, X-XSS-Protection, and strict CORS domain isolation.
