SECURITY ARCHITECTURE

Defensive Engineering and API Protection

Security principles applied systematically across authentication, authorization, and data isolation layers.

🛡

Method-Level API Authorization

Spring Security annotations validate roles on individual controller methods, returning standard 403 Forbidden responses on unauthorized operations.

🔑

Stateless JWT Authentication

Tokens are digitally signed using HMAC-SHA256, carrying subject and role claims validated on every inbound API call.

🔒

Ownership and IDOR Protection

Employee requests are bound to the authenticated user ID. Inbound requests to view or modify records verify user ownership before processing.

🌐

Nginx Edge Gateway

Configured with defensive HTTP headers including X-Frame-Options, X-Content-Type-Options nosniff, and controlled CORS origin policies.
